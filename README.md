# 202507042TALLERFINALCARRERITAS
Un juego de carreras donde puedes correr diferentes mapas con muchos objetivos siendo muy divertido para el usuario
# FASE1
Se llama carreritas es muy divertido para el anfitrión es jugable para cualquier edad es muy versátil y no muy comun como todos los juegos ya que incluye muchas metas y desarrollado 
# FASE2
La carrera continúa por un camino rodeado de árboles y naturaleza. Aparecen curvas más cerradas, rampas y zonas con barro que reducen la velocidad. El jugador debe controlar mejor el vehículo para no salirse de la pista.
# FASE 3
Una pista llena de arena, dunas y caminos irregulares. Hay saltos grandes y tramos donde el vehículo puede perder estabilidad. Además, algunas tormentas de arena reducen temporalmente la visibilidad.
# FASE 4
La última fase y la más desafiante. La carrera ocurre alrededor de un volcán activo, con lava, puentes estrechos, curvas peligrosas y grandes saltos. El jugador debe llegar a la meta antes de que el tiempo se acabe para convertirse en el campeón.
